# Landing interest and approved examples

The hero suggests communities locally. It does not run a live scan, send email, enrol a newsletter or call a model. Submitting an email saves interest and reveals up to three independently approved existing examples, not product-specific scan results. With no approved rows, the examples section is absent and capture remains available. No real examples are seeded by this change.

## Configuration and launch prerequisites

Liam configures the public `NEXT_PUBLIC_TURNSTILE_SITE_KEY` at build time and adds the staging hostname to the existing widget. `TURNSTILE_SECRET_KEY` is required server-side even in local development for this endpoint; the generic public guard's development bypass cannot enable capture. The existing visitor salt and public guard tables are also required. This change supplies no keys and changes no Worker configuration. Apply migrations only through the authorised release process. Merge remains gated on #98/#100 production acceptance.

## Explicit approval

`POST /api/admin/hero-examples` requires an existing authenticated admin session, a same-origin request and ownership of the requested workspace. It is intended for Liam's explicit approval of dogfood picks after #98 is live. There is no automatic promotion, bulk import or public workspace query.

The JSON request contains `workspaceId`, `opportunityId`, `documentId`, `excerpt`, and `approvePublicDisplay: true`. The explicit boolean records the approval act; it must never be generated by an autonomous background task. Actor and time come from the server session and server clock. Unknown fields (including forged approver fields) are rejected. IDs select one existing evidence document belonging to that opportunity in the authorised workspace, and are not copied into the public store. No opportunity summary, draft, score, metadata or workspace payload is copied.

Before approval, Liam must review the source for publication rights and privacy, confirm the title and source date, and select a contiguous verbatim excerpt of no more than 25 whitespace-separated words. Missing dates, missing titles, unsafe URLs, mocked documents, paraphrases and longer quotes are rejected. Approval copies only platform, source-derived community, source title, canonical URL, quote and posted date, plus server-derived approval fields. For Reddit, community comes from the source URL's subreddit path; otherwise it is the source hostname. Approval is publication consent for those exact fields; do not approve private customer material.

The public query selects only display fields from `hero_example` rows with both approval fields set, never approver account details. It returns at most three rows after successful Turnstile verification and lead storage. Unapproved rows have no public output. Public responses are not cached. The email is trimmed and lowercased before a unique-index conflict is ignored, so repeat submissions neither overwrite the initial description nor disclose an existing address. No message is sent.
